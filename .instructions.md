# Kobo Glo HD Compatibility Requirements

This project MUST maintain compatibility with **Kobo Glo HD e-reader browser**, which has very limited CSS and JavaScript support (similar to old WebKit browsers from ~2010).

## Critical Constraints

### ❌ FORBIDDEN CSS Features
- **NO Flexbox** (`display: flex`, `flex-direction`, etc.)
- **NO CSS Grid** (`display: grid`)
- **NO CSS Transforms** (`transform: translate()`, `rotate()`, etc.)
- **NO CSS Transitions** (`transition: all 0.3s`, etc.)
- **NO CSS Animations** (`@keyframes`, `animation:`)
- **NO Box Shadows** (`box-shadow:`)
- **NO Advanced Selectors** (`:not()`, `:nth-child()`, etc.)
- **NO CSS Variables** (`var(--color)`)

### ✅ REQUIRED CSS Patterns
- Use **`float: left/right`** for side-by-side layouts
- Use **`overflow: hidden`** to clear floats
- Use **`width: calc()`** for calculated widths (basic math only)
- Use **simple positioning** (`position: relative/absolute`)
- Use **basic borders** instead of shadows for depth
- Use **`:active` pseudo-class** for instant state changes (no transitions)

### ✅ Safe JavaScript Features
- Basic ES5 syntax (no arrow functions in critical code)
- `localStorage` API (supported)
- `Date` objects and basic manipulation
- `setInterval`/`setTimeout`
- Basic DOM manipulation
- Audio API may work but wrap in try-catch

### Testing Checklist
Before committing changes to `main` branch:
1. ✅ No flexbox or grid layouts
2. ✅ No transforms or transitions
3. ✅ No box-shadows
4. ✅ Layout uses floats or simple positioning
5. ✅ Buttons work with just `:active` state (no hover animations)

## Example: Breaking Change vs. Compatible Change

### ❌ BREAKS Kobo (commit 3d90f5f):
```css
.act-grid {
  display: flex;  /* Flexbox not supported! */
  gap: 12px;
}

.act-btn {
  box-shadow: 4px 4px 0 #888;  /* Not supported! */
  transform: translate(1px, 1px);  /* Not supported! */
  transition: all 0.1s ease;  /* Not supported! */
}
```

### ✅ WORKS on Kobo (commit af9d3a2):
```css
.act-grid {
  overflow: hidden;  /* Simple float clearing */
}

.act-btn {
  float: left;  /* Old-school layout */
  width: 25%;
  border: 3px solid #000;  /* Simple borders work */
}

.act-btn:active {
  background: #000;  /* Instant state change */
  color: #fff;
}
```

## Development Workflow

- **`main` branch**: Stable, Kobo-compatible code only
- **`timer` branch** (or feature branches): Experimental features with modern CSS
- Test on Kobo before merging to main
- When in doubt, check commit `af9d3a2` for compatible patterns

## Why These Constraints?

The Kobo Glo HD browser is essentially frozen in time (~2010-2012 era WebKit). Modern CSS features simply don't exist in its rendering engine. Any use of flexbox, transforms, or transitions will cause layout to break completely or render incorrectly.
